 **Azure Stream Analytics**，是实时数据流分析服务。它允许用户从多个数据源 (如 Azure Event Hubs、Azure IoT Hub、Azure Blob Storage 等) 收集、处理和分析实时数据流。

[Azure Stream Analytics job metrics](https://learn.microsoft.com/en-us/azure/stream-analytics/stream-analytics-job-metrics) 介绍了一些指标，包含: **Backlogged Input Events** (积压的输入) 、**Late Input Events** (延迟的输入) 、**Out-of-Order Events** (乱序)
