## 1. 介绍

[Azure Monitor](https://learn.microsoft.com/en-us/azure/azure-monitor/overview) 是综合监控方案，会收集、分析数据，并可自定义对应方案。通过 Azure Monitor 可最大化应用的可用性和性能。 Azure Monitor 使用Azure Monitor agent 去收集数据，data collection rule(DCR) 定义收集数据的规则， data collection endpoint(DCE) 定义了数据放送到的端点。

[Azure application Insights](https://learn.microsoft.com/en-us/azure/azure-monitor/app/app-insights-overview) 是 Azure 的 APM 工具，它属于 Azure Monitor。它使用 Azure Monitor Application Insights agent 收集数据。相对 Azure Monitor 而言，application insight 更专注性能相关的信息收。**适用例: App Service**
